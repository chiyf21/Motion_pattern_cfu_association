# 05: Local mechanical module embedded in distributed Ca network

This experiment starts from the spatial modules in experiment 03 and connects them to temporally significant CFUs from experiment 04. The aim is to test whether one local mechanical module is associated with multiple distributed upstream Ca signals.

Inputs are the spatial-module tables from 03, significant-pair tables from 04, pattern masks/activations from 01, and CFU files from 02. `run_module_network.py` builds the network; `render_module_cfu_spatial_gallery.py` renders the spatial gallery; `00_input_version_audit.md/csv` records input provenance. The current result contains 34 q<0.05 module–CFU edges involving 8 modules.
